# E-commerce Churn Prediction

Comparison of tree classifiers, boosting models, feature engineering, feature selection, imbalance handling, calibration, and probability ensembles on a cleaned 5,630-customer dataset.

The selected Extra Trees classifier uses 500 trees, 18 predictors, and a development-selected churn threshold of 0.45. Identical predictor profiles are grouped together during splitting and cross-validation. The final holdout is evaluated after model selection.

| Locked-test metric | Extra Trees | Matched 12-feature Random Forest |
| --- | ---: | ---: |
| Accuracy | 97.25% | 95.12% |
| Churn precision | 94.89% | 86.02% |
| Churn recall | 88.36% | 84.66% |
| Churn F1 | 91.51% | 85.33% |
| Average precision | 97.47% | 95.15% |

The holdout contains 1,126 customers, including 189 churners. Historical reported Random Forest scores are descriptive references with different test membership. The cleaned source's preprocessing lineage could not be fully audited; external and temporal validation remain necessary.

## Project contents

- `src/`: training, preprocessing, evaluation, and experiment code.
- `configs/`: experiment configuration.
- `tests/`: validation checks.
- `artifacts/models/`: fitted pipelines and model metadata.
- `results/tables/`: aggregate metrics, search trials, and threshold results.
- `figures/`: publication figures.
- `reports/`: findings, limitations, and reproducibility guide.
- `research_paper/`: editable LaTeX manuscript, bibliography, figure generator, and compiled paper.

Raw workbooks, customer-level predictions, split identifiers, the customer-level training workbook, local dependencies, and temporary execution files are excluded from this public repository.

## Setup and reproduction

Use Python 3.14 and install the recorded package versions:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Supply your authorized copy of `Task2_Complete_Data_Quality_and_Cleaning.xlsx` in `input_sources/`, with its original `Cleaned Data` sheet. The source SHA-256 is recorded in the model metadata. The input file is ignored by Git.

```bash
python -m src.experiment_runner
python research_paper/scripts/generate_figures.py
python -m pytest -q
```

The full test suite requires the private input and customer-level artifacts generated by the experiment runner. On a public checkout, these four artifact and arithmetic checks can run without customer data:

```bash
python -m pytest -q -k 'confusion_arithmetic or metadata_and_model_reload or final_test_access_contract or required_tables_exist'
```

Compile the paper from `research_paper/` using `tectonic main.tex` or a compatible LaTeX installation.
