# Research paper package

Run the complete experiments from the project root:

```bash
python -m src.experiment_runner
python research_paper/scripts/generate_figures.py
python -m pytest -q
```

From this directory, compile `main.tex` with `tectonic main.tex` or a compatible LaTeX installation. The paper uses measured results. The author line is anonymous because no verified identity or affiliation was supplied. Reproduction requires an authorized local copy of the input workbook; see the project README.
